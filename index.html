CineBase API Reference

Welcome to the CineBase Video API. Our robust endpoints provide seamless access to trending movies, comprehensive metadata, direct streaming URLs, and subtitles. Connect your application to a massive library of high-quality media.

Base URL

https://movie-terms.vercel.app

All API requests must be made over HTTPS. Append your generated API key in the headers as Authorization: Bearer YOUR_KEY.

GET

Fetch Trending (Trading) Media

Returns a list of currently trending movies and TV shows across the platform.

GET /api/trending?limit=24

Parameters

limit (Optional) Integer. Default 24. Number of items to return.
GET

Search Catalog

Query the database for specific movies, anime, or K-Dramas.

GET /api/search?q={query}&limit=24

Parameters

q Required. String. The search term (e.g., "Inception" or "anime").
limit (Optional) Integer. Default 24.
GET

Get Media Details

Fetch deep metadata including synopsis, cast, IMDB ratings, duration, and TV season structures.

GET /api/details?id={detailPath}

Parameters

id Required. String. The detailPath obtained from Search or Trending.
GET

Movie Streaming Sources

Retrieve direct MP4/M3U8 URLs and qualities for a specific movie.

GET /api/movie?id={detailPath}
GET

TV Episode Streaming Sources

Retrieve direct streaming URLs for a specific season and episode of a TV series.

GET /api/tv?id={detailPath}&season={s}&episode={e}

Parameters

id Required. String. The series detailPath.
season Required. Integer. Season number.
episode Required. Integer. Episode number.
GET

Fetch Subtitles

Retrieve available SRT subtitle tracks in multiple languages.

GET /api/subtitles?id={detailPath}[&season={s}&episode={e}]
