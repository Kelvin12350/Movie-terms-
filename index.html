Required Configuration (CORS Bypass)

If you call our API directly from your frontend code using an absolute URL like https://movie-terms.vercel.app/..., the browser will block it with a 405 Method Not Allowed CORS error. You must route your requests through your own local domain.

If you use Vercel: Create a vercel.json file in your root folder. This tells Vercel to securely forward your local /api/ calls to our servers behind the scenes.

vercel.json
{ "rewrites": [ { "source": "/api/:path*", "destination": "https://movie-terms.vercel.app/api/:path*" }, { "source": "/proxy-api/:path*", "destination": "https://movie-terms.vercel.app/proxy-api/:path*" } ] }

Frontend Global Setup

Define these exact constants at the top of your JavaScript file. This ensures all your requests use the secure local proxy path defined in your vercel.json.

JavaScript Constants
const API_KEY = 'cb_live_YOUR_SECRET_KEY'; const BASE_API = ''; // Empty string ensures requests hit your local proxy rewrite const STREAM_PROXY = '/proxy-api/stream'; const DL_PROXY = '/proxy-api/dl';

Troubleshooting & Edge Cases

"items.forEach is not a function"

The API wraps metadata arrays under variable non-standard keys (like items or list). Looping blindly will crash your app. Use this safe extractor:

Safe Array Extractor
function extractArray(data) { if (Array.isArray(data)) return data; if (!data) return []; const keys = ['results', 'items', 'list', 'data']; for (let k of keys) { if (Array.isArray(data[k])) return data[k]; } return []; }

"This subject is a tv" Error

If you fetch the movie endpoint but the ID belongs to a TV show, the API rejects it. Catch the error and auto-retry as a TV series.

Auto-Retry Logic
let res = await fetch(`/api/movie?id=\${id}`); let data = await res.json(); if (data.error && data.error.includes('This subject is a tv')) { // Auto-Heal: Switch to TV endpoint res = await fetch(`/api/tv?id=\${id}&season=1&episode=1`); data = await res.json(); }

Search Catalog

Search the database for specific keywords to fetch Categories (Anime, K-Drama, Movies) or specific titles.

JavaScript (Fetch via local proxy)
// Fetch Anime const anime = await fetch(`/api/search?q=anime&limit=24`); // Fetch K-Drama const kdrama = await fetch(`/api/search?q=korean%20drama&limit=24`); // Specific Movie const movie = await fetch(`/api/search?q=Deadpool&limit=24`);

Media Details

Fetch deep metadata (synopsis, cast, IMDB, genre) using the detailPath.

JavaScript (Fetch via local proxy)
const res = await fetch(`/api/details?id=\${encodeURIComponent(detailPath)}`); const details = await res.json();

Direct Download Request

Forces an attachment download instead of browser playback. Append the desired filename in the query string.
