API Reference

Welcome to the full CineBase Video API documentation. Our endpoints provide seamless access to everything from trending catalogs and media metadata to direct video streaming proxies, downloads, and subtitles.

Base URL & Authentication

https://movie-terms.vercel.app

All API requests must be made over HTTPS. Pass your generated API key in the headers as Authorization: Bearer YOUR_KEY.

GET

Fetch Trending Media

Returns a list of currently trending movies and TV shows across the platform.

GET /api/trending?limit=24

Query Parameters

limit Optional. Integer. Default 24. Number of items to return.
GET

Search Catalog

Query the database for specific movies, anime, or K-Dramas.

GET /api/search?q={query}&limit=24

Query Parameters

q Required. String. The search term (e.g., "Inception").
limit Optional. Integer. Default 24. Max results to fetch.
GET

Get Media Details

Fetch deep metadata including synopsis, cast, IMDB ratings, duration, and TV season structures.

GET /api/details?id={detailPath}

Query Parameters

id Required. String. The detailPath obtained from Search or Trending endpoints.
GET

Movie Streaming Sources

Retrieve direct MP4/M3U8 URLs, quality options, and sizes for a specific movie.

GET /api/movie?id={detailPath}

Query Parameters

id Required. String. The movie detailPath.
GET

TV Episode Streaming Sources

Retrieve direct streaming URLs for a specific season and episode of a TV series.

GET /api/tv?id={detailPath}&season={s}&episode={e}

Query Parameters

id Required. String. The series detailPath.
season Required. Integer. Season number.
episode Required. Integer. Episode number.
GET

Stream Video Proxy (CORS Bypass)

Internal proxy to securely stream video chunks or fetch subtitle text tracks directly into HTML5 players while bypassing browser CORS blocks.

GET /proxy-api/stream?url={url}&dp={dp}

Query Parameters

url Required. URL. The encoded raw media or SRT URL from the streaming endpoints.
dp Optional. String. The detailPath of the media, used for internal routing.
GET

Download Media File

Proxy endpoint to force a direct file download (attachment) of media files, bypassing browser playback rules and CORS restrictions.

GET /proxy-api/dl?url={url}&name={name}&dp={dp}

Query Parameters

url Required. URL. The encoded raw media URL.
name Required. String. The desired output filename for the user's device (e.g., movie_720p.mp4).
dp Required. String. The detailPath of the media.
GET

Fetch Subtitles

Retrieve available SRT subtitle tracks in multiple languages for a specific movie or episode.

GET /api/subtitles?id={detailPath}&season={s}&episode={e}

Query Parameters

id Required. String. The detailPath of the media.
season Optional. Integer. Required only if the media is a TV show.
episode Optional. Integer. Required only if the media is a TV show.
