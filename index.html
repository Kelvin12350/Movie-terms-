API Reference

Integrate CineBase's robust video infrastructure into your application. Build seamless streaming experiences, access comprehensive metadata, and generate direct proxy downloads.

Base URL

https://movie-terms.vercel.app

Authentication

1. JSON API Requests

For metadata endpoints (/api/search, /api/details, etc.), authenticate via the Authorization header.

Headers
Authorization: Bearer YOUR_API_KEY

2. Media Proxy & Downloads

HTML5 Video players and <a> download tags cannot send custom headers. You must append the key as a URL query parameter.

Query Parameter
?apikey=YOUR_API_KEY

Endpoints

GET

Search Catalog

Search the database for movies, anime, or K-Dramas.

ParameterDescription
qRequired The search term.
limitOptional Max items (Default: 24).
JavaScript (Fetch)
const response = await fetch('https://movie-terms.vercel.app/api/search?q=Inception', { method: 'GET', headers: { 'Authorization': 'Bearer cb_live_YOUR_KEY' } }); const data = await response.json();
GET

Get Media Details

Fetch deep metadata (synopsis, cast, IMDB, TV seasons) using a detailPath.

ParameterDescription
idRequired The detailPath from Search/Trending.
JavaScript (Fetch)
const response = await fetch('https://movie-terms.vercel.app/api/details?id=/movie/123', { headers: { 'Authorization': 'Bearer cb_live_YOUR_KEY' } });
GET

Movie / TV Stream Sources

Fetch raw M3U8/MP4 URLs. Use /api/movie for movies and /api/tv for series.

ParameterDescription
idRequired Media detailPath.
seasonTV Only Season number.
episodeTV Only Episode number.
JavaScript (Fetch)
// Movie Example await fetch('.../api/movie?id=/movie/123', { headers: { 'Authorization': 'Bearer YOUR_KEY' } }); // TV Example await fetch('.../api/tv?id=/tv/123&season=1&episode=4', { headers: { 'Authorization': 'Bearer YOUR_KEY' } });
GET

HTML5 Stream Proxy

Proxy endpoint to bypass CORS. Embed this directly into a <video src="..."> tag.

ParameterDescription
urlRequired Encoded raw media URL.
apikeyCritical Auth Key via URL.
HTML Usage
<!-- Notice apikey is passed in the URL --> <video controls src="https://movie-terms.vercel.app/proxy-api/stream?url=ENCODED_URL&apikey=cb_live_YOUR_KEY"> </video>
GET

Direct Download File

Forces a file attachment download, bypassing browser playback. Link directly via an anchor tag.

ParameterDescription
urlRequired Encoded raw media URL.
nameRequired Output filename (e.g., movie.mp4).
apikeyCritical Auth Key via URL.
HTML Usage
<!-- Generates a direct file download --> <a href="https://movie-terms.vercel.app/proxy-api/dl?url=ENCODED_URL&name=movie.mp4&apikey=cb_live_YOUR_KEY"> Download MP4 </a>
